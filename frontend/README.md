# frontend

React + TypeScript workbench for the finance ticket Agent.

Phase 1 status:
- ticket creation form
- ticket list
- selected ticket detail
- trace step timeline
- deterministic API integration

Run:

```powershell
cd D:\finance-ticket-agent\frontend
npm install
npm run dev
```

Build:

```powershell
cd D:\finance-ticket-agent\frontend
npm run build
```
